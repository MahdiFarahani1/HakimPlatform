📚 Hakim Platform

اپلیکیشن Hakim Platform یک پلتفرم محتوای دیجیتال چندرسانه‌ای است که با استفاده از Flutter توسعه داده شده است.

این پروژه با هدف ارائه یک تجربه کامل برای دسترسی به کتاب‌ها، مقالات، فایل‌های صوتی، ویدیوها، تصاویر و محتوای آموزشی طراحی شده است.

تمرکز اصلی پروژه بر روی ایجاد یک ساختار قابل توسعه، مدیریت state استاندارد، تجربه کاربری روان و معماری مناسب برای یک اپلیکیشن Production بوده است.

# 🏗️ معماری پروژه

ساختار پروژه بر اساس معماری **Feature First** طراحی شده است.

در این معماری هر قابلیت به صورت مستقل مدیریت می‌شود که باعث افزایش:

* خوانایی کد
* قابلیت توسعه
* نگهداری آسان‌تر پروژه
* جداسازی مسئولیت‌ها

می‌شود.

اصول استفاده شده در پروژه:

* Feature First Architecture
* Separation of Concerns
* Repository Pattern
* Dependency Injection
* BLoC / Cubit State Management
